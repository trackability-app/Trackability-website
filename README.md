# Trackability Website

GitHub-ready static website for Trackability.

## Publish
1. Upload all files and the `assets` folder to the root of your GitHub Pages repository.
2. Make sure `index.html` is in the repository root.
3. Enable GitHub Pages from the repository settings.
4. Point `trackability.in` to the published Pages site through your domain/DNS provider.

The working app CTA points to https://trackability-app.github.io/Trackability/ .
